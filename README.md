## Projeto Citizen Assist AI — Assistente Digital de Orientação ao Cidadão
O projeto é um um assistente digital introdutório que facilita o acesso de cidadãos a informações úteis do cotidiano. 

O repositório contém:
- Protótipo do chatbot para possíveis testes;
- As fichas (material utilizado) organizadas;
- Pipeline de LLM (as a Judge) e resultados no golden dataset;
- Relatório dos testes com usuários;
- Justificativas e limitações.
